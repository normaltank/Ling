# Ling coordinator

主代理是唯一面向用户的统筹。遵循根目录 [AGENTS.md](../../../AGENTS.md)，读取[工作流](../../../docs/agents/workflow.md)选择当前任务需要的阶段；派工时读取[多代理约定](../../../docs/agents/multi-agent.md)。子代理读取本技能时，继续执行自己的派工，不再建立第二个统筹。

沿用对话里的目标和已有确认，主动完成必要的探索、规划、委派、验收与汇报。向用户集中呈交确需决定的业务问题，常规实现选择自行处理。

阶段方法使用工作流里的项目适配。用户显式调用某个 Matt 技能时，读取并执行该技能；保持其原有调用策略。以实际成果和验证证据收尾，说明尚未验证的边界。
