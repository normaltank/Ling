# 用国产模型恢复建库，按实际效果决定 GraphRAG 版本

当前选择指定的 **DeepSeek V4.1 Flash 1017 + 已恢复的 GraphRAG 0.5 应用入口**。GraphRAG 3.3 已通过真实建库和独立查询，本轮同资料同题比较未显示值得立即替换应用的整体收益；暂不迁移原网页，保留新版候选和后续接入方案。[比较与结论](https://github.com/normaltank/Ling/issues/7)

老师遇到的是旧模型下线后，新语料无法完成要求 JSON 返回的批量 index；已有在线对话仍可使用。离线 index 仍可调用国产云模型。完成目标应是“新语料建库 → 项目使用新知识回答”，这条路径已在本地小批通过原接口和网页验证。[原应用恢复](https://github.com/normaltank/Ling/issues/6)

## 两条方案与实际选择

- **换兼容国产模型：合理，已验证。** Flash 1017 支持 JSON Object；0.5 可以保留结构化输出检查并恢复建库。所有本轮 DeepSeek 调用锁定 Flash，禁止 Pro。[官方接口](https://api-docs.deepseek.com/api/create-chat-completion/)
- **最小修改不兼容参数：合理，但仍须解析和字段校验。** 仅取消约束不能保证报告完整。本项目把必要适配放在项目侧；3.3 使用模型支持的 JSON Object，同时保留本地字段校验，未修改官方安装包。[新版实测](https://github.com/normaltank/Ling/issues/5)

## 这次比较说明什么

同六篇完整资料、同 Flash 1017、同十题，统一主要设置后由三位新上下文代理匿名对照原文评分，先锁分再揭示版本：两版均七题完整正确，另外三道 Global 题均存在遗漏或无原文支持的说法。新版有局部改善，旧版也有更严重的个别错误；不能宣布旧版普遍更准，也没有证据把升级本身当作效果修复。评阅属于代理原文核对，未由老师或专业使用者验收。

十题查询的峰值保守估算费用分别约 **$0.0357 / $0.0344**，差距很小。旧版同配置冷建约 $0.0525；新版共同配置由已付费缓存估算约 $0.0518，并非第二次冷建实测。原新版默认社区大小与旧版不同，评分前已纠正；缓存回放时间不作冷建时间。所有原配置、失败及重放记录保留，本轮全部模型费用保守估算约 **$0.272**，非发票金额。[过程修正](https://github.com/normaltank/Ling/issues/7#issuecomment-6893801217)

## 后续与改选条件

当前保留已完成原应用闭环的路径；先处理 Global 的遗漏与无依据推断，不能期望换版本自然消失。后续若代表性问题显示新版减少重要错误，或出现具体的新能力、旧依赖维护阻碍，再将新版建库接到原 HTTP 和网页，验收历史、语料范围、引用、费用、并发和回退。独立查询成功不当作应用升级完成。

学校部署、全量语料成本、长期质量及正式多人容量仍待实际环境验证。[完整待办](../teacher-todo.md)
