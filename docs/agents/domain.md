# Domain docs

本仓库采用 single-context：领域词汇放在根目录 `GLOSSARY.md`，架构决策放在 `docs/adr/`。

## 读取顺序

探索领域概念或设计决策前，读取现有 `GLOSSARY.md` 及与任务相关的 ADR。若以后出现 `GLOSSARY-MAP.md`，按其中的上下文指针读取相关词汇表。

文件尚不存在时直接继续工作；术语和决策实际确定后，由 domain-modeling 工作流按需建立，无须预先生成空文档。

## 使用规则

- 工单、设计、代码与测试中的领域概念使用词汇表规定的名称。
- 新概念未在词汇表定义时，先判断是否为现有概念的同义词，再记录确有必要补充的术语。
- 提案与现有 ADR 冲突时，指出具体 ADR 及重新讨论的理由。
